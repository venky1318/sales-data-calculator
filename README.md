# Sales Data Calculator

## Project Overview

The Sales Data Calculator is a Python-based application that analyzes a collection of sales values and calculates important statistical measures, including total sales, average sales, highest sale, and lowest sale.

The project demonstrates how Python's built-in functions can be used for basic numerical data analysis.

## Objective

To understand basic numerical data analysis using Python and calculate sales statistics from a manually created dataset.

## Problem Statement

Analyzing sales data manually can be time-consuming and may lead to calculation errors. This project automates basic sales calculations and presents the results in a clear format.

## Technologies Used

- Python 3
- Visual Studio Code
- GitHub

## Dataset

The project uses ten fictional sales records stored in a Python list.

Sales values:

12000, 15000, 18000, 10000, 22000, 25000, 14000, 30000, 17000, 27000

## Features

- Stores sales data in a Python list.
- Calculates total sales using `sum()`.
- Calculates average sales.
- Identifies the highest sale using `max()`.
- Identifies the lowest sale using `min()`.
- Validates sales data before processing.
- Displays results in a structured format.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

`python sales_data_calculator.py`

On Windows, you can also try:

`py sales_data_calculator.py`
